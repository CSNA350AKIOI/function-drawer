# 函数绘制器 · function-drawer

一个**零依赖的单文件**网页函数图像绘制器：打开 `index.html` 即可使用。输入表达式自动绘图，**可以拖动坐标轴**、平移画布、任意缩放。

## 快速开始

```bash
# 方式一：直接双击 index.html

# 方式二：本地静态服务器
python3 -m http.server 8000        # 然后访问 http://localhost:8000

# 方式三：npx serve .
```

## 交互

| 操作 | 效果 |
| --- | --- |
| 拖拽空白处 | 平移整个坐标系 |
| **拖拽 x 轴 / y 轴** | 单独移动该坐标轴（光标变成 ⇕ / ⇔） |
| 滚轮 / 双指捏合 | 以光标（两指中点）为中心缩放 |
| `Shift` + 滚轮 | 只缩放 x 轴 |
| `Alt` + 滚轮 | 只缩放 y 轴 |
| 双击 | 放大 1.7 倍 |
| 方向键 / `+` `-` / `0` | 平移、缩放、重置视图 |
| 鼠标悬停 | 十字准线 + 曲线取点读数 |
| 输入表达式时 | 弹出函数候选下拉，`↑` `↓` 选择，`Enter` / `Tab` 补全，`Esc` 关闭 |
| 精确解标注 | 每条曲线自动标出**零点**与**极值点**（空心圈 / 实心点 + 精确文字） |
| 触屏 | 单指拖动、双指捏合缩放 |

侧栏可以增删函数、临时隐藏某条曲线、插入示例函数，并把当前画面**导出为 PNG**。

## 精确零点与极值

每条曲线下方会列出用**符号求解**（不是采样、不是数值近似）得到的零点与极值：

```
f₁  sin(x)     零点  x = −3·π，−2·π，−π，0，π，2·π，3·π   通解 x = πk
               极值  极小 (−5·π/2, −1)  极大 (−3·π/2, 1) …  通解 x = π/2 + πk
f₂  x²/4 − 2   零点  x = −2·√2，2·√2
               极值  极小 (0, −2)
```

同样画布上会标记：零点画空心圈并标注 `x = …`，极大/极小画实心/空心点并标注 `max/min (x, y)`；
点位太密时会自动只保留圆点、错开文字，避免糊成一团。

- 结果始终是**精确形式**：`±2√2`、`π/6 + 2πk`、`ln(3)/2`、`√e`、`⁶√2`、`atanh(1/2)`、`sin(1/2)` …
- 解不出来（例如 `exp(x) - x` 这种超越方程）会明确写「无法精确求解」，绝不用近似值糊弄；
- 分母为 0 的点（如 `sin(x)/x` 的 `x = 0`）会被剔除；
- 极值只在**真正的极值点**标注：`cos(x) - x` 的驻点是拐点、`x^(1/3)` 的竖直切线都不会被误标；
- 尖点也会处理：`|x| - 1`、`sqrt(25-x^2)` 的端点都能标出极值。

底层是一个手写的 CAS（有理数 BigInt 精确算术 → 表达式 AST → 有理函数范式 → 符号求解），
全部内联在 `index.html` 里，没有任何第三方依赖。

## 表达式语法

- 四则运算 `+ - * / ^`（`**` 也当作幂），括号，隐式乘法：`2x`、`3(x+1)`、`(x+1)(x-1)`、`2sin(x)`
- 常量：`pi` `π` `tau` `τ` `e` `phi` `φ`
- 函数：`sin` `cos` `tan` `sec` `csc` `cot` `asin` `acos` `atan` `sinh` `cosh` `tanh` `asinh` `acosh` `atanh`
  `sqrt` `cbrt` `abs` `sign` `floor` `ceil` `round` `trunc` `exp` `ln` `log`(=`lg`/`log10`，也支持 `log(x, base)`)
  `log2` `min` `max` `mod` `pow` `hypot` `atan2`
- 单参数函数可省略括号：`sin x`、`√x`、`∛x`
- 中文标点、全角字符、`×` `÷` `−` 会被自动纠正为对应符号

## 实现要点

- 无第三方依赖、无构建步骤；Canvas 2D 绘制，改动后按 `requestAnimationFrame` 合并重绘
- 递归下降解析器把表达式**直接编译成 JS 源码**（`new Function`），每条曲线只编译一次，绘制时仅做数值求值
- 采样步长固定 0.5 屏幕像素，抗锯齿平滑；遇到断点时用细分采样判断是极点还是普通跳变
  （`1/x` 会断开，`floor(x)` 的台阶保留），避免出现跨越渐近线的错误竖线
- 刻度用 1/2/5×10ⁿ 自适应，主次网格随缩放自动增减；坐标轴被拖出画面时仍保留边缘刻度
- 单一 `view` 状态 {原点屏幕位置, 每单位像素数}，缩放/平移只是对它的线性变换
- 精确求解：表达式 → 有理函数范式（分子/分母多项式，系数为 BigInt 有理数 + π/√/原子符号）
  → 多项式因式分解 / 有理根定理 / 精确二次公式 / 三角·指数·对数求逆 → 解族 `x₀ + 2πk`
  → 在可见范围内枚举 k 得到具体点；求导后同样流程求极值，尖点/端点用左右函数值判定
